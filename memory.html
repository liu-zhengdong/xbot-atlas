身份与记忆

核对于 2026-10-16 d04f79e上一层 · XBot：新人导览internal/memory/internal/person/
30 秒版

人是跨 Bot 的全局身份；记忆分人、Bot、Bot 与人三层，以 Markdown 加索引存放。

边界

负责：人的身份映射、三层记忆和冲突规则。不负责：跨设备同步的传输（见 机器与设备）。

怎么运转

  • 人是跨 Bot 的全局身份。各个 Link 负责把外部账号映射到同一个人。
  • 记忆分三层：人的记忆（所有 Bot 共享，每条注明是哪个 Bot、什么时间写的）、Bot 自己的记忆、Bot 和某个人之间的记忆（其他人看不到）。
  • 冲突规则：关于人本身的事实，以最新的为准；关于怎么做事，以 Bot 自己的记忆为准。
  • 存储方式：可以直接编辑的 Markdown 加索引；分常驻层（每次都进上下文，有大小上限）和日志层（需要时检索）。
  • 资料库不单独做：Bot 直接读用户本机的文件和笔记。
